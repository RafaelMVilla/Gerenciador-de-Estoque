# 📚 Nome do Projeto
"StockUp"

# 🧾 Descrição
A nossa API simula uma solução para o controle e gerenciamento de estoque para uma empresa de TI.
Permite: 
- Cadastro de Dispositivos;
- Alteração de Dispositivos;
- Listagem de Dispositivos;
- Exclusão de Dispositivos;

# 🛠️ Tecnologias Utilizadas
- Linguagem: C# (.NET 8)
- Framework: ASP.NET Core
- ORM: Entity Framework Core
- Banco de Dados: MySQL
- Front-end: JavaScript
- Versionamento: Git + GitHub


# 🚀 Como Executar o Projeto
Pré-requisitos
- .NET SDK 8.0+
- MySQL instalado
- Git instalado
- Live Server instalado

# Passos:
# 1. Clone o repositório
git clone https://github.com/RafaelMVilla/Gerenciador-de-Estoque

# 2. Acesse a pasta do projeto
cd GerenciadordeEstoque

# 3. Restaure os pacotes
dotnet restore

# 4. Execute a aplicação
dotnet run --project StockUp

# 5. Execute o live server
Clique em Go Live
